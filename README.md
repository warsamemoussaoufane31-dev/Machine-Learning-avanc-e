## 📚 TPs Disponibles

### Day 1 : California Housing Price Prediction
**Dossier** : `day-1-tp1-california-house-ml/`

Projet de Machine Learning visant à prédire le prix médian des maisons en Californie à partir du dataset classique "California Housing". Le projet suit un pipeline complet : récupération des données, exploration, préparation, modélisation, évaluation, sauvegarde, et mise à disposition d'une API pour la prédiction.

**Fonctionnalités** :
- Téléchargement automatique du dataset
- Préparation des données avec `ColumnTransformer` et `Pipeline`
- Entraînement de plusieurs modèles (régression linéaire, arbres, forêts aléatoires, SVR, MLP)
- Évaluation par validation croisée (RMSE)
- API FastAPI pour les prédictions

### Day 2 : Arbres de Décision
**Dossier** : `day-2-tp1-tree/`

TP en préparation sur les arbres de décision et leur utilisation en Machine Learning.

### Day 3 : Use Case - Investor Risk Tolerance
**Dossier** : `day-3-tp2-use-case-investor-risk-tolerance/`

TP en préparation sur l'évaluation de la tolérance au risque des investisseurs.
